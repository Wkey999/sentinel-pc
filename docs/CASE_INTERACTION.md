# 案例与对话交互

- 「新对话」只清空当前会话界面，不立即创建案例。完成问诊并执行检查时才持久化一条记录。
- 「一键体检」首次使用直接开始一轮；已有体检时打开最近一次。工具栏「重新体检」才明确开始新一轮。
- 查看最近案例只加载记录；切换到硬件信息、工具或设置后回来，保持当前会话，不重放启动动作。启动动作只在对应新会话消费一次，执行入口有同步防重入锁。
- 检查执行前就展示本条记录；失败后「继续检查」复用原案例，避免每次重试堆积草稿。检查进行中可浏览其他功能，暂不切换案例、重命名或删除，以保留取消与结果状态。
- 最近案例展示所有记录，列表可滚动。每条记录末尾的菜单支持重命名与删除。新体检自动用日期时间命名；普通问诊用首句摘要命名。重命名只改变标题，不改变报告、计划或授权；新名称由后端校验并保存到 SQLite。
- 删除需用户在应用中确认。删除成功后刷新侧栏；若删除当前案例则回到空白会话。失败时在对话框显示原因。不会自动批量删除旧数据。
- 诊断页重复的「详细信息」卡片已移除；完整硬件配置保留在独立「硬件信息」页。

新增 `rename_case` 命令按现有主窗口权限边界开放。回归包含名称校验、计划与报告不被改写、重启后的名称保留，以及合成案例的选择、改名和删除。浏览器交互验证使用离线 Mock，未删除用户真实案例。
