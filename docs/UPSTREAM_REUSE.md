## 已提供的回归线索

reference/UPSTREAM_VERIFICATION.json 记录了提供方在 PowerShell 7.6.9、合成输入与 Mock 系统接口下的六项观察。本轮仅核读，未独立复现：

- R01–R03：额外字段、越界整数、嵌套缺字段被接受；需要闭合并递归执行 Schema 验证。
- R04：USB 工具参数映射 ErrorsOnly / OnlyErrors 不匹配。
- R05：PowerShell 集合输出未保持有效 JSON；统一 envelope 必须测 0/1/多行。
- R06：中文与英文空事件消息分支不同；使用稳定错误标识。

另外必须测试相同事件 ID 不同 provider、不同应用/服务/启动会话不误关联、同型号多盘不合并，以及版本号不被当成 IP 误脱敏。

以上研究不能替代本项目单测、PowerShell 5.1、真实采集、真实格式或发行工件许可验收。
