# 语音输入

首页与案例对话共用 `VoiceComposer`，麦克风入口始终可见。录音状态使用圆角输入区：上方实时显示识别中的文字，下方为取消、实际音量波形、停止、发送。中间结果可被后续识别修正，不必等停止才显示；长文本可换行滚动，并跟随最新结果。没有返回文字时显示「正在聆听，请说话…」，不生成假的识别内容。

- 取消：丢弃本次听写，保留开始前草稿。
- 停止：等待最终转写，回到可编辑输入框，不发送。
- 发送：等待最终转写，再调用原有提交入口，避免截断和重复发送。
- 切换功能页、检查开始、组件卸载或取消时终止本次会话。单独用于绘制音量的音轨、定时器、音频上下文均释放；迟到的权限和识别回调不再写入草稿。
- 超时和识别失败保留已识别文字，要求用户检查后手动发送。

识别沿用已有 `SpeechRecognition` / `webkitSpeechRecognition` 服务，语言为 `zh-CN`，支持连续结果。服务由浏览器 / WebView 内核提供，可能需要联网，不能承诺离线中文识别或每种内核均可用。未新增付费语音 API，也未将录音交给 DeepSeek；波形读取在本机进行，不保存录音。内核不支持、权限未开启、网络或服务错误时提供明确提示，使用 Windows `Win + H` 作为回退。

参考：[Microsoft SpeechRecognition API](https://learn.microsoft.com/en-us/microsoft-edge/web-platform/speech-recognition-api)、[停止识别并等待结果](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/stop)。

验证覆盖模拟识别的最终结果、取消、停止、发送、超时、迟到回调、麦克风资源释放及不支持的内核。浏览器交互验证使用模拟音频；未自动采集用户真实麦克风或向识别服务发送音频。实际麦克风、权限和中文识别服务仍需在桌面端试用确认。
