## 仍有的展示问题

- 历史案例载入分支仍硬编码 `demo.analyze_fixture` 和 0.2s，即使报告 provenance 是 native_collected。真实报告与采集逻辑未因此变成模拟；应按保存的 tasks/provenance 展示历史任务。
- 聊天工具列表将 completed_partial 映射为 Failed，容易把“来源暂不支持”表达成“失败”。报告覆盖与未知说明是正确的，但工具图标还应区分部分完成、不支持和实际失败。
- 窗口标题仍含“离线预览”，部分指标名/对象 hash 未转成面向用户的中文名称。
- 本轮重启后案例数量差异待确认启动方式/数据目录并复测；不能只凭源码回归通过就宣称所有历史恢复流程完成验收。

以上是剩余 UI 表达与验收缺口，不能把本轮结果写成所有界面问题全部消失。
