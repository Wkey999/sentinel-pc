## 背景

当前目录只有 Git 元数据，无受跟踪文件、应用代码、提交、README 或锁文件。检查 D:/、D:/文档/、D:/文档/ChatGPT/ 与项目根目录，没有发现 AGENTS.md。按新项目准备，不覆盖已有工程。

## 决策

1. Windows x64 桌面产品；Tauri 2 + Vue 3 + TypeScript + Rust，SQLite 元数据与案例附件分离。
2. 执行权在 Rust；仅注册固定动作与受限参数，不暴露通用 Shell、任意文件访问或模型命令执行接口。
3. 首发真实采集只做 windows.system_snapshot 与 windows.event_window，固定 PowerShell 5.1 脚本；权限拒绝与空结果分别保存。
4. 第三方工具只做 CrystalDiskInfo 文本、smartctl JSON 导入，不下载、安装或随包分发检测程序。
5. 离线规则闭环优先，模型默认关闭。Disabled/Mock 先行，未经明确配置和同意不调用付费服务。
6. 观察、候选解释、未知项分开；不将单条 41、WHEA、崩溃模块或无日志当成具体硬件确诊。
7. 选择性参考 Pulse 解释/关联/脱敏和 PC-AI 只读查询设计，不引入上游常驻服务、完整模型栈、原生 DLL 或修复脚本。
8. 不自动修复、不提权、不做压力测试；支持/收款入口关闭。

## 版本与环境

Node 24.16.0、npm 11.13.0 已验证可运行；官方 Vue/Vite 当前入门要求与该 Node 版本相容。Tauri 需要 Rust MSVC、Microsoft C++ 工具及 WebView2。具体前后端包版本、Rust 版本与锁文件属于 C01，本轮不声称已完成依赖解析或构建。

Rust/Cargo 当前不可用；C++/SDK/WebView2 有安装记录但原生构建尚未验证。系统注册表的产品名与 build 显示存在差异，CIM 查询在本执行环境拒绝访问，暂不冻结支持版本。详见 ENVIRONMENT.md。

## 待确认但不阻止离线开发

- 自有代码 Apache-2.0 仅为原规格建议，未获所有者确认，不生成 LICENSE 或法律署名。
- 代码签名、正式发布渠道、稳定 Windows 验收系统待明确。
- 两类报告缺合法脱敏真实样本，先用合成数据，只能标为预览格式支持。
- 上游文件未在本轮重新取得；研究中的代码/许可观察不是本轮独立复验结果。真正迁入前必须核对固定提交、依赖与完整 MIT 声明。
